## 📁 Структура проекта

```
hotel-project/
├── index.html       — Главная страница (витрина номеров)
├── auth.html        — Страница входа / регистрации
├── client.html      — Личный кабинет клиента
├── admin.html       — Панель администратора

└── js/
    └── app.js       — Логика приложения, данные, утилиты
```

## ✨ Функциональность

### Главная страница
- Витрина отеля с описанием
- Каталог номеров с фото, ценами и описаниями
- Кнопка бронирования (переводит на авторизацию, если не вошёл)

### Авторизация (`auth.html`)
- Вход в аккаунт
- Регистрация нового клиента
- Автоматическое перенаправление по роли (клиент / админ)

### Личный кабинет клиента (`client.html`)
- Просмотр своих бронирований с фильтрами
- Поиск и бронирование номеров с расчётом стоимости
- Отмена бронирования
- Редактирование профиля

### Панель администратора (`admin.html`)
- Дашборд с ключевыми показателями
- Управление всеми бронированиями (смена статуса)
- CRUD номеров (добавить / редактировать / удалить)
- Список клиентов со статистикой

## 🛠 Технологии

- **HTML5** — разметка
- **CSS3** — стили (CSS Variables, Grid, Flexbox, анимации)
- **Vanilla JavaScript** — логика без фреймворков
- **localStorage** — хранение данных в браузере

## 🌐 Размещение на GitHub Pages

1. Создайте репозиторий на [github.com](https://github.com)
2. Загрузите все файлы проекта в репозиторий
3. Перейдите в **Settings → Pages**
4. В разделе **Source** выберите ветку `main`, папку `/ (root)`
5. Нажмите **Save** — сайт будет доступен по адресу:  
   `https://ВАШ_ЛОГИН.github.io/ИМЯ_РЕПОЗИТОРИЯ/`

> ⚠️ Данные хранятся в `localStorage` браузера — каждый пользователь видит только свои данные. Для учебного проекта этого достаточно.
